LucidGloves: building a VR haptic glove

A practical walkthrough of the Prototype 4/4.1 design: translate finger movement into virtual hands, then add physical resistance with servo-driven haptics.

Original project: LucidVR / Lucas VRTech and contributors.
Document: a source-based learning guide for Elvis Tang’s portfolio · Summer of 2020.

LucidGloves is open source. Its repository provides firmware and printable hardware files under the MIT license. This guide documents the upstream build process; it does not claim original authorship of the glove or report a personally verified build.

01 / Understand the system

A string from each fingertip turns a spring-loaded spool connected to a potentiometer. The microcontroller reads those changes and sends finger data to OpenGloves. A mounted controller or tracker supplies hand position; the glove’s finger sensors alone do not provide spatial tracking.

Finger motion → spool + potentiometer → ESP32 → USB or Bluetooth Serial → OpenGloves → SteamVR
Supported application → force-feedback command → servo → resistance at the spool

The supplied Lucas VRTech tutorial demonstrates Prototype 4. Follow its ESP32 route here, using matching 4/4.1 hardware files. The repository also contains other revisions; do not mix their parts or pin assignments. Finger tracking and force feedback have different application requirements, so test them independently.

03 / Print and check the fit

Download the hardware files. For each hand, prepare five haptic spools, covers, tensioners and holders; five fitted end caps; finger guides; and the correct left/right rigid mount and controller/tracker slider.

The printing guide suggests a 0.4 mm nozzle, 0.2 mm layers, 10–20% infill and 0.8 mm shells. Parts are designed to print flat without supports. Match holders to both the potentiometer type and mounting method, and resize end caps for each finger.

Checkpoint: trial-fit one complete module before printing the remaining set. Check that the spool rotates and the slider seats securely. See video, 2:33.

04 / Assemble the glove

  1. Open a badge reel carefully and recover its spring and string. Secure the potentiometer in the tensioner, then fit the spring as shown in the tutorial. Confirm that rotation returns smoothly.
  2. Thread the string through the haptic spool and cover, seat the spool on the potentiometer, and close the module. Wind the string and check its return action.
  3. Fit the module and servo to the holder. Leave the servo horn off until the software calibration stage. Repeat for all five fingers.
  4. Attach end caps and guides to the glove. Add foam under the rigid mount, then fit straps and elastic. Route each string through its finger guides and secure it at the end cap.

Checkpoint: open and close each finger individually. Every spool should turn and retract without snagging or pulling the mount out of place. Complete hot-glue work away from bare skin. Follow 3:22–7:03 in the tutorial for the small spring and string details.

05 / Wire the sensors and servos

Use the full-resolution wiring diagram and the pin definitions in your downloaded firmware together. With power disconnected, connect each potentiometer to 3.3 V, ground and its assigned analog input. Connect each servo’s signal to its assigned output; power the motors from the servo supply and share ground with the ESP32.

Checkpoint: check polarity, continuity and finger-to-pin labels before powering up. Do not power the servo bank from the ESP32’s 3.3 V pin. Secure connections so finger movement cannot pull them loose. The tutorial explains this at 7:05–9:25.

06 / Upload and validate the firmware

  1. Install Arduino IDE, the ESP32 board package and the ESP32Servo library using the firmware setup guide. Install the USB-to-serial driver appropriate to your board if needed.
  2. Download or clone the repository. Open firmware/lucidgloves-firmware/lucidgloves-firmware.ino. Select your actual board and USB port.
  3. Match sensor and motor pin definitions to the wiring. Configure the calibration input, enable force feedback for this build, and disable unused joystick inputs. Start with USB Serial before moving to Bluetooth.
  4. Compile and upload. Open Serial Monitor at the firmware’s baud rate; the video uses 115200. Move one finger at a time to check that its readings change consistently.

The wiki explains that newer firmware uses letter-number encoding, so output may differ from older tutorials. Check FLIP_POTS if readings move in the wrong direction. For wireless operation, configure COMM_BTSERIAL, set a device name, upload again and pair the device. Close Serial Monitor before another application opens the port. See 9:26–12:28.

07 / Connect to VR and calibrate

  1. Install OpenGloves on Steam and activate the driver. Select the correct hand, enable feedback and match the communication mode to the firmware. Set the USB port or Bluetooth device name.
  2. Mount the controller/tracker securely and start SteamVR. Open and close your hand through its full comfortable range to calibrate the fingers. Use the configured calibration button to reset if needed.
  3. Use the driver’s pose calibration controls to align the virtual hand with the physical glove. The tutorial demonstrates manual and automatic alignment.
  4. Test servo extension and retraction before fitting the horns. Following the tutorial’s orientation, fit each horn so the extended state stops spool movement and the retracted state allows it. Keep an accessible power disconnect and stop if motion is uncomfortable.
  5. Use the force-feedback demo described in the video to test contact and release. Verify current demo/mod availability through OpenGloves before attempting a game-specific setup.

These are the tutorial’s setup steps at 12:29–15:12; interface labels can vary by release. Haptics require a supported application or integration. Do not assume every SteamVR game supports force feedback.

08 / Verify and document the result

Use these as acceptance checks for your own build. No test results are claimed in this source-based guide.

  • Mechanics: all five strings retract, finger guides stay attached and the mount remains stable.
  • Sensors: each finger changes the correct channel smoothly over its calibrated range.
  • Tracking: the virtual hand follows the mounted tracker and finger motion remains consistent.
  • Haptics: each servo engages and releases in the supported demo without trapping a finger or resetting the board.
SymptomFirst checks
No serial dataData cable, board driver, selected port, baud rate and firmware upload.
Wrong or noisy finger motionPin mapping, loose connectors, string friction, calibration and potentiometer direction.
Board resets during hapticsServo supply capacity, shared ground and ESP32 power stability.
Tracking works, haptics do notMotor power, firmware feedback setting, driver feedback option and application support.

Save your firmware revision, board/library versions, pin map, build photos and observed results. Record failures as well as successes so future changes can be compared against a known configuration.
